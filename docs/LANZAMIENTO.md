- [ ] Confirmar el nombre profesional, títulos académicos, especializaciones y maestrías de Andrés.

- [ ] Subir su fotografía real y contar con autorización para usarla.
- [ ] Revisar licencia y permisos de todas las fotografías editoriales.
- [ ] Confirmar programas, temarios, duración, horarios, docentes, cupos y precios.
- [ ] Configurar WhatsApp y correo reales en `assets/js/config.js`.
- [ ] Sustituir `privacidad.html` por política de tratamiento de datos personales completa y verificada.
- [ ] Establecer términos de inscripción, pagos, cancelaciones, devoluciones y servicio al cliente.
- [ ] Revisar el encuadre normativo colombiano: educación informal vs. educación para el trabajo y el desarrollo humano; no ofrecer títulos o certificados oficiales sin las autorizaciones correspondientes.

- [ ] Integrar una pasarela de pagos real si se requiere cobro online; nunca recoger datos de tarjetas en un formulario casero.
- [ ] Implementar plataforma de estudiantes, base de datos y autenticación si se desea un aula virtual privada.
- [ ] Agregar recursos y artículos originales o con derechos de uso.
- [ ] Probar la web en móvil, tablet y escritorio; verificar enlaces y accesibilidad.

**Importante:** el contenido del sitio es una propuesta de identidad y oferta académica, no una representación verificada de credenciales, matrículas, tarifas o servicios existentes.
